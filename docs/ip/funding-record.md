## Why this exists

The kit is reusable across programs only if the company keeps rights to it. Under [DFARS 252.227-7014](https://www.acquisition.gov/dfars/252.227-7014-rights-other-commercial-computer-software-and-other-commercial-computer-software-documentation.), noncommercial software developed exclusively at private expense is delivered with restricted rights and title stays with the company. Mixed funding generally yields government purpose rights, and exclusively government funding yields unlimited rights. SBIR and STTR awards use [DFARS 252.227-7018](https://www.acquisition.gov/dfars/252.227-7018-rights-other-commercial-technical-data-and-computer-software%E2%80%94small-business-innovation-research-program-and-small-business-technology-transfer-program.) instead.

Asserting restricted rights later depends on records made now, while the work happens.

## Evidence we keep

- Dated, scoped commits in this repository (Conventional Commits, enforced by commitlint).
- Timesheets and charge codes for everyone who works on the kit.
- The log below, updated whenever the funding for kit work changes.

## Rules

1. This repository holds kit work only. Contract-funded application code lives in program repositories.
2. Before kit work is charged to a new charge code, add a row to the funding log.
3. Add a row when a funding source starts or ends, when someone joins or leaves kit work, or when a contract starts using the kit.
4. Synthetic data only. No contract data, CUI, or classified information in this repository.
5. Every delivered copy of the kit carries the restricted-rights legend (Step 12).
